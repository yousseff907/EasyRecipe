# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub instead: open the Security tab of this repository and click "Report a vulnerability".

A useful report says which endpoint, page or file is affected, how to reproduce the problem, and what an attacker could do with it.

## Supported versions

There are no releases. Fixes go to the `main` branch, so run the latest `main` if you host your own instance.

## Scope

This policy covers the code in this repository. Problems with someone else's hosted instance should go to whoever runs it, and problems in the services EasyRecipe uses (Gemini, OpenAI, Resend, Cloudflare Turnstile, Google sign-in) should go to those vendors.
